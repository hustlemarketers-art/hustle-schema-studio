FROM CODE TO YOUR WEBSITE

Make the markup match the page.

Google recommends JSON-LD. Accurate content and accessible pages matter as much as valid code.

01

Choose the right page

Add product schema to the product page, article schema to the article, and business details to a relevant business page. Use real, visible information.

Keep IDs stable, such as https://yourwebsite.com/#organization. Connect entities by reusing those IDs.

02

Check existing markup

SEO plugins and themes may already create schema. Inspect the source and coordinate with that output before adding another block.

Do not add conflicting prices, duplicate business identities, fabricated ratings, or every template to every page.

03

Install the JSON-LD

Copy the generated script into the relevant page’s HTML <head> or body, ideally in the HTML served by your site.

On WordPress, use your existing SEO plugin’s supported schema controls or a trusted snippet tool with page targeting. Do not paste scripts into a plain text paragraph block.

04

Verify on the live page

Use the Rich Results Test’s URL mode after publishing. Check Googlebot access, robots.txt, HTTP response, noindex directives, and crawlable images.

Use Search Console URL Inspection to check Google’s view, then monitor relevant reports. Correct markup does not guarantee crawling, indexing, rankings, or rich results.

Before you publish

A few rules worth knowing

  • FAQPage is still a Schema.org type, but Google retired FAQ rich results in May 2026.
  • Service, Person, and WebPage can describe entities without a dedicated rich-result feature.
  • WebSite markup can support site names. The old sitelinks search box has been retired.
  • This Product template uses an Offer for the product-snippet path. It is not a complete merchant-listing or product-variant builder.
  • These 12 templates are a focused starting set. Imported types outside the checker’s rules are labelled as unchecked.

Rules reviewed 12 October 2026. Review the latest documentation before production use.
